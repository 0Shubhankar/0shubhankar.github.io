# Greenville 0.2 — park-focused cinematic prototype
Local preview using shared UUE directly, with independent GIE 0.1. Original public Project 20, Gotham, Project 42 and shared UUE are not modified. Night default, high activity, day toggle. No internal branding or separate visual legend.

Three original chapters and 96 routes. Each choice has a concrete explanation; intermediate choices show immediate changes, then a chapter review after two model years. Final report compares a matched no-policy case. All assumptions in gie/README.md apply. Financing receipts, costs, canopy and access are illustrative. No actual network walking accessibility, cooling, biodiversity or employment is claimed.

Camera anchors: three existing UUE park objects ordered by x/z and assigned to fictional income districts. They are visual stand-ins, not validated district geography. Planting beds and condition strips inside existing parks are representative cues; no actual UUE land conversion is performed. They may overlap existing park furniture/trees; verify visually. The model's land inventory is independent of UUE map geometry.

Run from UUE root: npm run dev -- --port 5180 --strictPort; open http://localhost:5180/p20-cinematic/. Engine tests: cd p20-cinematic/gie && npm test. Browser checklist: all three park visits, day/night, all chapter reviews, final score, replay, console errors. Production integration remains separate.

## 0.2.2 Park differentiation
Daylight default; unnumbered story titles; normalized park exhibits show land provision, condition and canopy. Amenities are illustrative quality proxies, not separate GIE variables. Shared UUE state unchanged.
