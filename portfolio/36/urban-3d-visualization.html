This simulation represents a 3D city model where different districts are categorized based on socio-economic data such as population density, real estate prices, income distribution, and vacancy rates. The districts are depicted using textured cubes in a 3D space, each corresponding to a different socio-economic class, such as Lower-Income District, Working-Class District, and Upper-Middle-Class District. Each district has a calculated affordability index, which is the ratio of real estate prices to income, and this index impacts how particles (representing people) move between districts.

This visualization allows users to interact with the city model by adjusting various global modifiers through a control panel created using dat.GUI. These modifiers include:

  • Population Density Modifier: Globally adjusts the population density in all districts.
  • Real Estate Price Modifier: Changes the real estate prices in the districts.
  • Income Modifier: Alters the income distribution across all districts.
  • Vacancy Rate Modifier: Modifies the vacancy rates in each district.

As users modify these global parameters, the socio-economic data for each district is updated, including the affordability index. This influences how particles (representing individuals) move between districts. Particles move based on affordability and population density: districts with better affordability indices enable faster movement, drawing more particles to them. Particles change color based on the affordability of the district they move into: green for affordable, yellow for moderately affordable, and red for less affordable.

In summary, this simulation demonstrates how socio-economic factors like affordability and population density influence migration patterns within an urban environment, with real-time changes reflecting shifts in these dynamics.
