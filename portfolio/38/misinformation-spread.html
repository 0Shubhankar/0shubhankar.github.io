This simulation is a visual model of how information spreads through a network of connected points, known as nodes. These nodes can either accept or reject the information based on several factors, such as susceptibility, which represents how likely the nodes are to believe the information. The simulation allows users to adjust parameters, such as susceptibility thresholds and information persuasiveness, to observe how these variables affect the spread of information. You can start the simulation by clicking 'Start Spread' in the GUI panel and use the sliders to modify the settings and see the impact in real-time. The purpose of the simulation is to demonstrate how misinformation or correct information can propagate across a network and how different parts of the system are affected.

In the simulation, a set of nodes is created. These nodes are represented by small glowing spheres, and they symbolize individuals, organizations, or systems within a network. Each node is connected to other nodes by lines, which represent the flow of information between them.

The process of information flow starts from the root node, which is the first node created in the center. The root node begins to spread information, which could be true or false. This is visualized by small particles or dots moving from one node to another along the connecting lines. When the information reaches a node, that node decides whether to accept or reject the information based on its susceptibility, which determines how easily it believes the information.

Each node has a susceptibility level, which is a value that indicates how likely it is to believe and spread misinformation. If a node’s susceptibility is high, the node turns red, showing that it has accepted the misinformation. However, if a node has a low susceptibility or is connected to weaker, less influential nodes, it can resist the misinformation. Resistant nodes stay in their original color, such as green, to indicate that they did not accept the misinformation.

The particles continue to move between nodes, visualizing how information or misinformation spreads across the network. As the simulation progresses, some nodes turn red, showing they have accepted the misinformation, while others remain green, indicating resistance.

A network is created by first generating a root node. New nodes are then connected to the root node and to other existing nodes, forming a web-like structure. These new nodes are connected to others using curved lines, simulating the relationships between individuals, organizations, or entities in a social or informational network.

After the network is built, the simulation initiates the spread of information. Information particles travel between the nodes, with the speed and likelihood of spreading determined by the strength of the connections between nodes. Each node calculates whether it will accept or reject the information based on its susceptibility score. If the node's susceptibility is high enough, it will turn red to indicate that it has accepted the misinformation.

As the simulation runs, various metrics are tracked in real-time and are displayed on the left side of the screen. These metrics include the rate of spread, which measures how fast misinformation is spreading through the network, and the conversion ratio, which shows the percentage of nodes that have accepted the misinformation. This is displayed as a green progress bar. Another important metric is the number of resistant nodes, showing how many nodes resisted the misinformation. This is represented by a red progress bar. Additionally, the average path length indicates how far the misinformation has traveled through the network, and the node influence score measures how many nodes each individual node has influenced.

Each node is assigned a random susceptibility value, which determines how likely it is to accept misinformation. When the information reaches a node, the simulation compares the node's susceptibility to a threshold value, which can be adjusted through the control panel. If the node's susceptibility is higher than this threshold, it changes color to red, indicating that it has accepted the misinformation.

Once a node accepts misinformation, it can continue to spread it to the nodes it is connected to, creating a chain reaction. Particles, or small dots, flow between the connected nodes to visualize the spread of information or misinformation, moving along the lines that connect the nodes in the network.

Throughout the simulation, various metrics are calculated, including how many nodes have accepted misinformation, how many nodes have resisted, and how far the information has spread across the network. The simulation also tracks which nodes are the most influential by counting how many other nodes they have convinced or converted.

Users can interact with the simulation using the control panel provided on the right side of the screen. This control panel allows users to adjust the colors of the nodes and the information particles, as well as control how fast the information spreads and how persuasive the information is. Additionally, users can adjust the susceptibility of the nodes and press a start button to begin the spread of information once the network is built.

On the left side of the screen, a real-time metrics panel is displayed. It shows important statistics such as how fast the misinformation is spreading, how many nodes are converting to misinformation, and how many nodes are resisting it. These metrics are updated dynamically as the simulation progresses.

This simulation is a tool for studying how information or misinformation spreads through a network. By adjusting parameters such as susceptibility and connection strength, users can observe how easily a network can be influenced or how resistant it is to false information. This model can be useful for understanding the dynamics of social media, studying epidemic models, or modeling the spread of rumors and public opinion. In summary, this simulation provides a visual and interactive way to explore how networks of people or systems behave when exposed to spreading information, especially misinformation.
